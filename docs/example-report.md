# Example attendance comparison

This is an illustrative, shortened report with fictional participant names.
It is not a real student roster or a captured university response.

```text
🏸 Beginners · 12.11.2026 20:00 МСК
Снимок записи: 19:00:05 · Проверка: 12.11 22:10

📋 Были записаны за час — 3
1. Example Player One
2. Example Player Two
3. Example Player Three

🚫 Исчезли из списка после снимка, без часов — 1
1. Example Player Two

✅ Пришли, часы выставлены — 1
1. Example Player One — 2 ч

❌ Не пришли / остались без часов — 1
1. Example Player Three

➕ Появились после снимка, без часов — 1
1. Example Player Four
```

Player Two no longer appears in the current table and has no saved hours. This
is a candidate for reviewing a late cancellation, not proof of who removed it
or the exact cancellation time. Player Three remains in the table with zero
hours. If the leader forgot to save hours, the report will reflect that omission.

The real report includes these interpretation limits. Repeating `/check` reads
the current hours again; it does not modify the original roster or the website.
